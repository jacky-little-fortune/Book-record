# 繪本借閱清單

在手機上記下香港公共圖書館的繪本：誰借了、何時要還、想再借哪幾本。資料只放在這部裝置，不會上傳，也不會傳送給圖書館。

網上版：<https://jacky-little-fortune.github.io/Book-record/>

用瀏覽器打開上面的網址即可。頁面可以離線使用；請先在有網絡時開啟一次，讓手機把頁面存下來。

## 每天怎樣用

1. 打開清單。預設只顯示「借閱中」。
2. 按右下角「新增」，填書名、作者、簡介、來源、索書號、ISBN。可以用條碼或 ISBN 查書名；索書號仍請照圖書館目錄抄。
3. 打開一本繪本，按「借出」。選媽媽卡、爸爸卡或女兒卡，以及借出日。到期日會用該卡的借期自動計算，確認前可以改，以便對齊圖書館印的日期。
4. 還書時按「歸還」。
5. 想再借的書，按星星。到「想借」可以一次複製純文字清單；手機有分享功能時，也可以直接分享。複製內容包含書名、作者，以及已經填了的索書號和 ISBN。
6. 「統計」按借出那一個月計次數。同一本書每借出一次計一次。

篩選可以同時點選多個。一本書要符合每一個已選條件才會出現。例如同時點「借閱中」和「將到期」，只會看到仍借出、而且快到期或已逾期的書。全部取消就顯示所有繪本。

「將到期」是指：仍在借出，而且到期日在今天起計 3 日之內（含今天），或者已經逾期。

## 用 ISBN 查書

在「新增繪本」或「編輯繪本」頁，ISBN 欄下面有「掃描條碼」和「查資料」。

用相機掃描：

1. 按「掃描條碼」。這時才會詢問相機權限，進入頁面時不會開相機。
2. 在 iPhone 請按「允許」。若按了「不允許」，可到「設定」→ Safari → 相機，改為允許這個網站，或改為手動輸入。
3. 把書背的 ISBN 條碼放進框裡。讀到後會自動填上書名、作者、簡介和 ISBN。
4. 每個欄位都可以再改。核對後按「儲存繪本」，才會寫進這部裝置。
5. 這部裝置沒有相機，或相機被拒絕時，畫面會說明原因，不會空白一筆帶過。

不開相機：

1. 輸入或貼上 10 位或 13 位 ISBN，橫線可以留著。
2. 按「查資料」。

查詢會先問 Open Library，那裡沒有再問 Google Books。只會送出 ISBN，用來取回公開書目，不會把借閱紀錄送到香港公共圖書館，也不會替你填索書號。來源和索書號仍要自己填。

找不到這本書時，會直接說明查不到，並保留 ISBN，方便你自己補上書名。查詢需要網絡。沒有網絡時，已經儲存的清單仍可查看和修改。

## 三張借書卡

借出中的繪本，清單那一行會鋪上該卡的顏色。借閱紀錄裡，每一次借出也沿用當時那張卡的顏色。

| 借書卡 | 顏色 |
| --- | --- |
| 媽媽卡 | 玫瑰色 |
| 爸爸卡 | 藍色 |
| 女兒卡 | 薄荷綠 |

## 到期日

三張卡的借期預設都是 14 日，可在「設定」各自修改。已借出的紀錄不會跟著新借期自動改。

到期日假設：香港公共圖書館一般圖書借期預設 14 日（可於設定調整）；實際以圖書館規定為準。

## 加入 iPhone 主畫面

請用 Safari 開啟 <https://jacky-little-fortune.github.io/Book-record/>。

1. 點畫面底部的分享按鈕（方框裡有一枝向上箭頭）。
2. 向下捲動分享選單，點「加入主畫面」。若沒看到，再往下捲，或在選單裡找「編輯動作」。
3. 名稱可保留「繪本借閱」，點右上角「加入」。
4. 之後從主畫面的圖示開啟。

第一次請在有網絡時打開。頁面存好之後，沒有網絡也可以查看和修改清單。

## 備份與匯入

清單存在這部裝置的瀏覽器裡。換手機、清除 Safari 網站資料，或刪除 App，紀錄會一併消失。換機或清理前請先備份。

下載：

1. 打開「設定」。
2. 按「下載 JSON 備份」。
3. 在 iPhone 上，檔案有時會直接打開預覽，而不是存進「檔案」。這時點分享，再選「儲存到檔案」。
4. 若按鈕列有「分享備份檔」，也可以直接存到「檔案」，或用 AirDrop 送到另一部手機。

匯入：

1. 在新裝置用 Safari 打開同一個網址，並加入主畫面。
2. 打開「設定」→「匯入 JSON 備份」。
3. 選先前儲存的 JSON 檔，再確認取代。
4. 匯入會用備份蓋過這部裝置上現有的繪本和借期設定。

設定裡也可以在清單還是空的時候載入範例繪本。範例只有書名和簡介，不會填上索書號或 ISBN，請自行對照圖書館目錄。

## 私隱

這是放在瀏覽器裡的靜態網頁，沒有帳號，也沒有伺服器資料庫。搜尋、借還、統計、備份都在這部裝置完成。查 ISBN 時，只會把該組 ISBN 送到 Open Library 或 Google Books。
